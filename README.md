# NOVA

NOVA is the social-platform project. This package is prepared for cloud Android builds, so AndroidIDE is not required.

## What is included now
- NOVA dark UI
- Home feed
- Search field
- Like/comment/share UI
- Hot section
- Create section
- LIVE section placeholder
- Profile/settings entry points
- Supabase-ready environment variables
- EAS configuration for an installable Android APK

## Important
This is the buildable application foundation. Real authentication, database sync, uploads, real LIVE streaming, calls, payments/ATOMA, AI moderation and payouts require their production credentials/services and are connected in later phases.

## Cloud build
Use Expo EAS Build. The `preview` profile is configured to produce an APK.
